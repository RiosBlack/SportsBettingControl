# Bibliotecas e Dependências

Principais bibliotecas utilizadas no ecossistema RiosBlack, divididas por categoria.

## Core Framework
- **next (15.2.8)**: Framework Full-stack React.
- **react (19)**: Biblioteca de componentes UI.
- **typescript**: Tipagem estática para todo o projeto.

## Estilização e UI
- **tailwindcss**: Utilitários CSS de baixo nível.
- **shadcn/ui**: Componentes de interface premium (Acessíveis e customizáveis).
- **lucide-react**: Conjunto de ícones vetoriais.
- **recharts**: Biblioteca de gráficos para visualização de estatísticas.
- **vaul / embla-carousel**: Componentes de UX para drawers e carrosséis.
- **next-themes**: Gerenciamento de modo Light/Dark.

## Backend e Banco de Dados
- **prisma**: ORM para PostgreSQL.
- **@prisma/client**: Cliente tipado para queries DB.
- **bcryptjs**: Criptografia de senhas.
- **next-auth (5.0.0-beta.29)**: Autenticação stateless.

## Utilitários
- **zod**: Schema validation para runtime.
- **date-fns**: Manipulação de datas e fusos horários.
- **sonner**: Sistema de notificações (toasts).
- **react-hook-form**: Gestão facilitada de formulários.
- **clsx / tailwind-merge**: Concatenação inteligente de classes CSS.

## Desenvolvimento (DevDependencies)
- **eslint**: Ferramenta de linting para qualidade de código.
- **postcss / autoprefixer**: Processamento CSS.
- **@types/node / @types/react**: Definições de tipos para o ambiente de desenvolvimento.
